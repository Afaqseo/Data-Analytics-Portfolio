# Layoffs Data Analysis Using SQL

Project Overview
This project focuses on cleaning, transforming, and exploring a layoffs dataset different countries at different stages of investments from around the world using MySQL.

The objective is to identify data quality issues, prepare the dataset for analysis, and discover meaningful insights about global company layoffs.

## Project Structure

- `Layoffs_Data_Cleaning.sql` – Data cleaning and transformation.
- `Layoffs_Exploratory_Data_Analysis.sql` – Exploratory data analysis.

## Tools & Technologies
- MySQL
- SQL
- MySQL Workbench

## Skills Demonstrated

### Data Cleaning
- Identifying and removing duplicate records.
- Handling NULL and missing values.
- Standardizing text fields.
- Converting date formats.
- Modifying column data types.
- Creating calculated columns.

### Exploratory Data Analysis
- Aggregate functions.
- GROUP BY and ORDER BY.
- Common Table Expressions (CTEs).
- Window Functions.
- DENSE_RANK().
- Rolling totals.
- Yearly and monthly analysis.

## Key Areas of Analysis
- Companies with the highest layoffs.
- Layoffs by industry and country.
- Yearly layoffs trends.
- Companies with the highest layoffs in each year.
- Monthly layoffs and cumulative totals.
